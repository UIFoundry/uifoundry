## Props

The FAQ_2 block accepts the following configuration from PayloadCMS:

<TypeTable
  type={{
    header: {
      description: "Main section heading displayed above FAQ items",
      type: "string",
      required: false,
      default: "Frequently Asked Questions",
    },
    subheader: {
      description: "Supporting description text displayed below the header",
      type: "string",
      required: false,
      default: "Still have questions? Check out our documentation",
    },
    documentationText: {
      description: "Link text for the documentation reference (displayed inline with subheader)",
      type: "string",
      default: "Check out our documentation",
    },
    documentationHref: {
      description: "URL link for the documentation reference",
      type: "string",
      default: "",
    },
    faq: {
      description: "Array of FAQ items with questions and answers",
      type: "array",
      default: "10 default FAQ items with platform-related questions",
    },
    "faq[].question": {
      description: "The FAQ question text",
      type: "string",
      required: true,
      default: "Can I host frontend and backend apps together?",
    },
    "faq[].answer": {
      description: "The answer text for the FAQ question",
      type: "string",
      required: true,
      default: "Yes, the platform supports full-stack applications...",
    },
  }}
/>

## Design Notes

This FAQ block features:

- **Collapsible disclosure panels**: Built with react-aria-components for accessibility and keyboard navigation
- **Multiple expansion support**: Users can expand multiple FAQ items simultaneously using `allowsMultipleExpanded`
- **Inline documentation link**: Documentation reference seamlessly integrated within subheader text
- **Clean centered layout**: Content constrained to 3xl width for optimal readability
- **Generous spacing**: 12-unit margin below header section and 16-unit vertical padding
- **Rounded disclosure styling**: Custom `--disclosure-radius` set to `xl` for modern appearance
- **Muted foreground color**: Subheader and link text use muted-fg for visual hierarchy
- **Hover states**: Documentation link includes hover:underline interaction
- **Dark mode support**: Uses CSS custom properties for theme-aware teal accent color
- **Flexible FAQ count**: Supports any number of FAQ items with sensible defaults (10 included)
- **Semantic HTML**: Proper heading hierarchy and accessible markup

Perfect for help centers, product documentation, landing pages, or any section requiring an organized Q&A format. The react-aria-components foundation ensures excellent keyboard navigation and screen reader support, making it ideal for accessible web applications.
