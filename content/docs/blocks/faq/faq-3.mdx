The FAQ_3 block accepts the following configuration from PayloadCMS:

<TypeTable
  type={{
    header: {
      description: "Main section heading displayed above FAQ items",
      type: "string",
      required: false,
      default: "Frequently Asked Questions",
    },

## Design Notes

This FAQ block features:

- **Custom emerald theme**: Beautiful emerald color scheme with light/dark mode variants using CSS custom properties
- **Gradient background**: Decorative gradient blur effect positioned at the top (visible in dark mode)
- **Accordion-style disclosure**: Built with react-aria-components for accessible, keyboard-navigable FAQ panels
- **Multiple expansion**: Allows multiple FAQ items to be expanded simultaneously
- **Rounded panels**: Extra-large border radius on FAQ panels for modern aesthetic
- **Collapsible support section**: Support link fields are organized in a collapsible admin panel
- **Dynamic theming**: Custom CSS properties for collapsed and expanded states:
  - Collapsed: Emerald-50/950 background with emerald-700/200 text
  - Expanded: Emerald-200/600 background with emerald-800/300 text
  - Borders: Emerald-600 with 20-30% opacity
- **Centered layout**: Max-width of 3xl for optimal reading width
- **Flexible FAQ count**: Supports 0-20 FAQ items with 10 comprehensive defaults
- **Inline support link**: Support link appears inline with subheader text
- **Responsive spacing**: Consistent padding and margins throughout

Perfect for FAQ sections, help centers, knowledge bases, or support pages. The emerald theming makes this variant stand out while maintaining excellent readability and accessibility through react-aria-components.
