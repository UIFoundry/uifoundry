## Design Notes

This FAQ block features:

- **Centered layout**: Maximum width of 3xl with centered content for focused reading experience
- **Accordion-style disclosure panels**: Clean expandable panels with custom color variables for collapsed and expanded states
- **Support link integration**: Dedicated support text with clickable documentation link at the top
- **Custom styling**: Uses CSS custom properties for theme flexibility with transparent collapsed background and muted expanded background
- **Multiple expansion support**: Allows multiple FAQ items to be expanded simultaneously for easy comparison
- **Default expanded state**: First FAQ item (index 1) is expanded by default to guide users
- **Responsive typography**: Large 4xl heading with clean muted text for support section
- **Keyboard accessible**: Built on react-aria-components for full keyboard navigation support

Use this component for help centers, product documentation, or any section where you need to provide answers to common customer questions. The centered layout and accordion-style panels make it ideal for standalone FAQ pages or sections within landing pages. The support link provides an escape hatch for users who can't find answers in the FAQ.
