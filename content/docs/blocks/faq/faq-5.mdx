## Design Notes

This FAQ block features:

- **Expandable disclosure panels**: Clean accordion-style interface built with react-aria-components for accessibility
- **Multiple expanded support**: Allows multiple FAQ items to be open simultaneously
- **Default expanded items**: Configure which FAQ items are expanded on page load using 1-based indices
- **Documentation link integration**: Inline documentation link within the subheader text for seamless navigation
- **Centered layout**: Focused 3xl max-width container for optimal reading experience
- **Minimal styling**: Transparent backgrounds with subtle color transitions on expand/collapse
- **Custom CSS properties**: Uses CSS custom properties for fine-grained color control
- **Flexible FAQ count**: Supports 0-20 FAQ items with consistent spacing

The component uses custom CSS properties for theming:
- `--disclosure-expanded-fg`: Text color when expanded (default: fg color)
- `--disclosure-collapsed-fg`: Text color when collapsed (default: muted-fg)
- `--disclosure-expanded-bg`: Background when expanded (transparent)
- `--disclosure-collapsed-bg`: Background when collapsed (transparent)

Use this component for comprehensive FAQ sections on landing pages, help centers, or product documentation. The centered layout and minimal styling make it ideal for focus-driven content where readability is paramount. The ability to pre-expand specific questions makes it perfect for highlighting important information.
