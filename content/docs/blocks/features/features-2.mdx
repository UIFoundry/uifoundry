## Props

The Features_2 block accepts the following configuration from PayloadCMS:

<TypeTable
  type={{
    header: {
      description: "Main heading text displayed at the top of the features section",
      type: "string",
      required: false,
      default: "Everything You Need to Ship Fast",
    },
    subheader: {
      description: "Supporting description text displayed below the header",
      type: "string",
      required: false,
      default:
        "Professional blocks, templates, and hosting solutions. Build stunning marketing sites with no-code ease, or customize everything with full developer control.",
    },
    features: {
      description: "Array of feature items, each with an icon, header, and description",
      type: "array",
      default: "6 default features",
    },
    "features[].icon": {
      description: "Lucide React icon name for the feature (e.g., 'Blocks', 'Zap', 'Palette')",
      type: "string",
      required: true,
    },
    "features[].header": {
      description: "Feature title text",
      type: "string",
    },
    "features[].description": {
      description: "Feature description text",
      type: "string",
      required: true,
    },
  }}
/>

## Installation

```bash
npx shadcn@latest add @uifoundry/features-2
```

If you encounter issues, check the [registry setup guide](/docs/registry-setup) for configuration help.

## Registry Dependencies

This component uses the following registry components:

- [Icon](/docs/ui/icon) - Dynamic Lucide React icon renderer by name
- [Header Field](/docs/fields/header-field) - PayloadCMS text field for headers
- [Subheader Field](/docs/fields/subheader-field) - PayloadCMS text field for subheaders
- [Icon Field](/docs/fields/icon-field) - PayloadCMS icon selection field with searchable dropdown
- [Description Field](/docs/fields/description-field) - PayloadCMS text field for descriptions
- [Block Constants](/docs/lib/block-constants) - Block slug and group constants for PayloadCMS blocks

## Dependencies

This component requires the following NPM packages:

- [React](https://github.com/facebook/react) - JavaScript library for building user interfaces
- [Next.js](https://github.com/vercel/next.js) - React framework for production
- [PayloadCMS](https://github.com/payloadcms/payload) - Headless CMS and application framework
- [Lucide React](https://github.com/lucide-icons/lucide/tree/main/packages/lucide-react) - Beautiful & consistent icon toolkit
