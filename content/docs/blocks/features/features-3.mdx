## Props

The Features_3 block accepts the following configuration from PayloadCMS:

<TypeTable
  type={{
    header: {
      description: "Main heading text displayed at the top of the features section",
      type: "string",
      required: true,
      default: "Powerful Features",
    },
    subheader: {
      description: "Supporting description text displayed below the header",
      type: "string",
      required: true,
      default: "Everything you need to build modern web applications with confidence",
    },
    features: {
      description: "Array of feature items, each with an icon, title, and description. Minimum 1 feature required. Displays in a responsive three-column grid on larger screens.",
      type: "array",
      required: true,
      default: "3 default features",
    },
    "features[].title": {
      description: "Feature title text",
      type: "string",
      required: true,
      default: "New Feature",
    },
    "features[].description": {
      description: "Feature description text",
      type: "string",
      required: true,
      default: "",
    },
    "features[].icon": {
      description: "Lucide React icon name for the feature with animated grid decorator background",
      type: "string",
      required: false,
    },
  }}
/>

## Installation

```bash
npx shadcn@latest add @uifoundry/features-3
```

If you encounter issues, check the [registry setup guide](/docs/registry-setup) for configuration help.

## Registry Dependencies

This component uses the following registry components:

- [Card](/docs/ui/card) - Card component with header and content sections
- [Icon](/docs/ui/icon) - Icon component for rendering Lucide React icons dynamically by name
- [Icon Field](/docs/fields/icon-field) - PayloadCMS icon selection field with searchable dropdown for Lucide React icons
- [Block Constants](/docs/lib/block-constants) - Block slug and group constants for PayloadCMS blocks

## Dependencies

This component requires the following NPM packages:

- [React](https://github.com/facebook/react) - JavaScript library for building user interfaces
- [Next.js](https://github.com/vercel/next.js) - React framework for production
- [PayloadCMS](https://github.com/payloadcms/payload) - Headless CMS and application framework
- [Lucide React](https://github.com/lucide-icons/lucide/tree/main/packages/lucide-react) - Beautiful & consistent icon toolkit
