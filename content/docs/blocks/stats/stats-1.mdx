## Design Notes

This statistics block features:

- **Centered layout**: Text content centered with `text-center` for balanced presentation
- **Grid-based cards**: Statistics displayed in responsive grid with `grid-cols-1 sm:grid-cols-2 lg:grid-cols-4` layout
- **Divided layout**: Uses `divide-y` and `divide-x` utilities to create visual separation between stat cards
- **Card styling**: Background with `bg-muted/50`, rounded corners, and border for subtle depth
- **Large stat values**: Values displayed prominently with `text-3xl` and `tracking-tight` for impact
- **Muted labels**: Stat names shown in `text-muted-fg` for visual hierarchy
- **Visual order**: Uses `order-first` to place values above labels in each card
- **Flexible count**: Supports 1 to 8 statistics with validation constraints
- **Compact spacing**: Efficient use of space with `p-8` padding and `mt-8` top margin
- **Max width constraint**: Content limited to `max-w-2xl` for readability, grid expands to `lg:max-w-none`
- **Container integration**: Uses Container component with vertical padding `py-6 sm:py-16`
- **Responsive text**: Header uses `font-normal sm:text-3xl`, subheader uses `text-lg/8`

Perfect for showcasing key performance metrics, business statistics, or product achievements. The card-based grid layout with divided sections creates a clean, organized presentation that scales well across different viewport sizes. The large numeric values with subtle labels make it easy to scan and digest important information quickly.
