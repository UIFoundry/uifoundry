## Design Notes

This statistics block features:

- **Optional eyebrow text**: Small label above the header for additional context
- **Bordered card design**: Statistics cards with subtle border and ring accents for visual depth
- **Ring offset styling**: Cards feature `ring ring-muted-fg/30 ring-offset-4 ring-offset-muted` for layered visual effect
- **Emphasis text pattern**: Each statistic combines large numeric value with bold emphasis text and supporting description
- **Responsive grid layout**: `grid-cols-1 sm:grid-cols-3` adapts from single column to three columns
- **Text hierarchy**: Large statistic (`text-3xl`), medium emphasis, and descriptive text create clear visual priority
- **Consistent spacing**: `gap-x-6 gap-y-6` between cards and `mt-12` separating content from statistics
- **Container integration**: Uses Container component for consistent page width and responsive padding
- **Max width constraint**: Content section limited to `max-w-3xl` for optimal readability
- **Flexible stat count**: Supports 1-6 statistics with `minRows: 1, maxRows: 6` validation
- **Color contrast**: Uses `text-primary-subtle-fg` for eyebrow, `text-fg` for main text, and `text-muted-fg` for descriptions

Perfect for landing pages, product pages, or marketing sites that need to showcase key metrics and achievements. The bordered card design with ring accents provides a modern, polished look while maintaining excellent readability and visual hierarchy. The emphasis text pattern makes it easy to scan important information quickly.
