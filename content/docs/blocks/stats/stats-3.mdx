## Design Notes

This statistics block features:

- **Animated number counter**: Uses the AnimatedNumber component for smooth digit transitions with customizable font size (64px)
- **Auto-increment functionality**: Optional continuous counting animation with configurable interval (default 3000ms)
- **Grid background pattern**: GridLines component creates subtle grid overlay with 2x2 cell dimensions
- **Gradient decorations**: Dual radial gradient overlays on left and right sides (hidden on mobile, visible on lg+ screens)
- **Text highlighting**: Parses description to bold specified text using `highlightedText` prop for emphasis
- **Bordered container**: Border top and bottom with muted foreground color (30% opacity) for subtle framing
- **Muted background**: Light background with `bg-muted` for soft contrast against page background
- **Centered layout**: All content centered using Container component with max-width constraints
- **Screen reader support**: Includes sr-only heading "Our stats" for accessibility
- **Isolation context**: Uses `isolate` class on gradients to control z-index stacking
- **Contain-strict**: Gradient containers use `contain-strict` for performance optimization
- **Responsive spacing**: Padding adjusts from `py-6` on mobile to `py-16` on larger screens with `py-16` inner container
- **Complex gradient calculations**: Multiple radial gradients with precise positioning, rotation, and HSLA color stops for depth
- **Typography hierarchy**: Large semi-bold number with tracking-tighter, centered max-width description with muted foreground

Perfect for landing pages, dashboards, or product pages requiring prominent statistics display with eye-catching animations. The auto-increment feature creates a dynamic, real-time feel ideal for showcasing metrics like active users, installations, or transactions.
