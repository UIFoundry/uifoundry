## Props

The Testimonials_1 block accepts the following configuration from PayloadCMS:

<TypeTable
  type={{
    header: {
      description: "Main heading text displayed at the top of the testimonials section",
      type: "string",
      required: false,
      default: "What our customers say",
    },
    subheader: {
      description: "Supporting description text displayed below the header",
      type: "string",
      required: false,
      default: "Authentic testimonials from thrilled users who've unlocked game-changing results with our platform.",
    },
    testimonials: {
      description: "Array of customer testimonials with avatar, name, role, and quote. Supports 0-20 testimonials.",
      type: "array",
      required: false,
      default: "9 default testimonials",
    },
    "testimonials[].name": {
      description: "Customer's full name",
      type: "string",
      required: true,
      default: "Isabelle Dupont",
    },
    "testimonials[].role": {
      description: "Customer's job title and company",
      type: "string",
      required: true,
      default: "Product Designer at Formly",
    },
    "testimonials[].avatar": {
      description: "URL to customer's avatar image",
      type: "string",
      required: false,
      default: "https://randomuser.me/api/portraits/women/44.jpg",
    },
    "testimonials[].quote": {
      description: "Customer testimonial text",
      type: "textarea",
      required: true,
      default: "Using this product has completely transformed our design workflow. It's fast, intuitive, and reliable.",
    },
  }}
/>

## Design Notes

This testimonial block features:

- **Centered grid layout**: Responsive grid that adapts from 1 column on mobile to 3 columns on desktop
- **Avatar prominence**: Large 2xl avatar images centered above each testimonial
- **Clean typography**: Italic quotes with muted styling for elegant presentation
- **Flexible testimonial count**: Supports 0-20 testimonials with consistent spacing
- **Centered alignment**: All content center-aligned for balanced visual impact
- **Professional styling**: Customer name and role clearly displayed below each quote

Use this component for social proof sections on landing pages, product pages, or anywhere you need to showcase customer feedback with a clean, professional appearance. The centered layout works particularly well for hero sections or standalone testimonial showcases.
