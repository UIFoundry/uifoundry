## Design Notes

This testimonials block features:

- **Rounded card design**: Testimonials displayed in modern rounded-3xl cards with border styling
- **Horizontal avatar layout**: Avatar and name/role displayed side-by-side for a clean look
- **Responsive grid**: Adapts from 1 column on mobile to 2 on tablet to 3 on desktop
- **Flexible testimonial count**: Supports 0-12 testimonials with sensible defaults (9 included)
- **Secondary background**: Cards use subtle secondary/20 background with dark mode support
- **Large avatar size**: Prominent lg-sized avatars for better visual hierarchy
- **Centered header section**: Section header and subheader are center-aligned above the grid
- **Italic quotes**: Blockquote text styled in italic with muted foreground color
- **Consistent spacing**: Balanced padding and gaps throughout the component

Perfect for social proof sections, customer testimonials, case studies, or user reviews. The horizontal avatar layout is ideal when you want to maintain a professional look while showing multiple testimonials in a compact grid format.
