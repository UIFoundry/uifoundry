## Design Notes

This testimonial block features:

- **Masonry layout**: CSS columns create a dynamic, Pinterest-style layout that adapts to content height
- **Responsive columns**: 1 column on mobile, 2 on tablet, 3 on desktop for optimal readability
- **Large decorative quotes**: Giant serif quotation marks add visual interest and emphasize authenticity
- **Avatar support**: Displays customer avatars or auto-generated initials for a personal touch
- **Hover effects**: Subtle shadow animation on hover enhances interactivity
- **Break-inside-avoid**: Prevents testimonial cards from splitting across columns
- **Consistent spacing**: Automatic gap and vertical spacing between testimonial cards

Source: @irsyad/testimonials-04 (IntentUI) - Modified for PayloadCMS integration with dynamic content and media upload support.

Use this component when you want to display multiple customer testimonials in an engaging, space-efficient layout. The masonry design naturally accommodates varying quote lengths while maintaining visual balance. Perfect for social proof sections on landing pages, product pages, or dedicated testimonials pages.
